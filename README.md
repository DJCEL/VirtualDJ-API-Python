# VirtualDJ-Python-API
An API in Python for VirtualDJ by using the Network Control plugin and/or reading the VirtualDJ database (.xml, .db)

It requires VirtualDJ Pro (www.virtualdj.com) with the Network Control Plugin enabled.

Update the `./src/virtualdj_client/client_config.py` file if you don't use the default values in VirtualDJ or to disable the log file.
